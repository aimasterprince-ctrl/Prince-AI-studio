PRINCE AI STUDIO — Android starter project

इस ZIP में Android Studio का शुरुआती प्रोजेक्ट है।
अभी इसमें:
- भक्ति और DJ/म्यूजिक वीडियो मोड
- टेक्स्ट से वीडियो प्रॉम्प्ट
- हिंदी गाने के बोल का शुरुआती ड्राफ्ट
- म्यूजिक जनरेशन प्रॉम्प्ट
- कॉपी बटन

महत्वपूर्ण:
यह अभी APK नहीं है और अपने-आप असली वीडियो/ऑडियो render नहीं करता।
असली AI वीडियो और गाना बनाने के लिए सुरक्षित backend और video/music generation APIs जोड़नी होंगी।
API secret key को Android ऐप के अंदर न रखें।

APK बनाने के लिए Android Studio में इस फ़ोल्डर को खोलें और Build > Build APK(s) चुनें।
इस प्रोजेक्ट को build करने के लिए Android Studio/SDK वाला कंप्यूटर चाहिए।
